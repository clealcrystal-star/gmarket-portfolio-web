# 정수정 G마켓 CRM Portfolio Web

원본 PDF/PPT 내용을 이미지로 유지한 React 스크롤형 웹 포트폴리오입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소를 열면 됩니다.

## Vercel 배포 방법

1. GitHub에 이 폴더를 업로드
2. Vercel 접속
3. Add New Project
4. GitHub 저장소 선택
5. Framework Preset은 Vite로 자동 인식
6. Deploy 클릭

## 이미지 위치

`public/slides` 폴더 안에 슬라이드 이미지가 들어 있습니다.
